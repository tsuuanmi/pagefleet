# PageFleet documentation

Documentation is classified by authority, not by chronology.

- [Requirements](requirements/README.md): draft, verifiable desired outcomes; **nothing is shipped**.
- [Research](research/README.md): date-stamped evidence and options, not commitments.
- [Proposals](proposals/README.md): candidate implementation awaiting acceptance.
- [Governance](governance/README.md): standard, local profile, checks, retired ledger.

Create an architecture, decision, engineering, security or operations area only when there is real knowledge of that class. See the [PageFleet profile](governance/documentation.md).
