# PageFleet

PageFleet is a **proposed** AI-assisted content studio for managing multiple authorized Facebook Pages. There is **no application or verified publishing integration** in this repository yet.

Initial use case: 10 Pages (7 share a subject; 3 cover other subjects). Planned flow: spreadsheet or manual content ideas -> AI-generated per-Page variants -> edit and approve -> schedule -> publish -> inspect results.

Develop first as a local web application, then deploy the same workflow on a VPS for unattended schedules. Minimize total ownership cost, not just monthly invoices.

Start with [documentation](docs/README.md). Product behavior is a [draft requirement](docs/requirements/product.md), tooling comparisons are [research](docs/research/README.md), and the initial [MVP architecture](docs/proposals/PROP-0001-local-first-mvp.md) is only a proposal.
