# PageFleet

PageFleet is a **proposed** AI-assisted content studio for managing multiple authorized Facebook Pages. There is **no application or verified publishing integration** in this repository yet.

Initial use case: 10 Pages in two Industries (construction works and granite) owned by one company. Planned flow: connect Pages with Facebook Login -> import a spreadsheet Batch or enter a Content idea -> AI-written per-Page variants -> review and approve the Batch -> Meta-native scheduling -> reconcile uncertain outcomes.

Develop first as a local web application, then deploy the same workflow on a VPS for unattended schedules. Minimize total ownership cost, not just monthly invoices.

Start with [documentation](docs/README.md) and the domain [glossary](GLOSSARY.md). Accepted rationale is in [decisions](docs/decisions/README.md).
